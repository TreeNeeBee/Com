## v3.1 核心架构更新

### 1. 零冲突槽位映射

**设计变更**:
```cpp
// v3.0: Hash 映射（可能冲突）
uint16_t slot = Hash(service_id, instance_id) % 1024;

// v3.1: 零冲突直接映射
uint16_t slot = service_id & 1023;  // 取低10位，天然映射
```

**优势**:
- ✅ O(1) 查找，无需哈希表
- ✅ 零冲突，service_id 高位段已隔离
- ✅ 广播完美映射：0xFFFF & 1023 = 1023

### 2. 槽位 0 保护机制

**设计目标**: 防止未初始化的 service_id 污染注册表

**实现方式**:
```cpp
inline uint32_t CalculateSlot(uint16_t service_id) {
    uint32_t slot = service_id & 1023;
    
    // 槽位 0 保护：禁止使用
    if (slot == 0) {
        return INVALID_SLOT;  // service_id 0x0000 或 0xF000 非法
    }
    
    return slot;
}
```

**保护范围**:
- ❌ service_id 0x0000 (QM Registry 槽位 0)
- ❌ service_id 0xF000 (ASIL-CD Registry 槽位 0)
- ✅ 运行时拒绝注册，抛出错误

### 3. 双注册表物理隔离

**v3.0 设计**:
- QM Registry: 槽位 0~923
- ASIL-D Registry: 槽位 924~1023

**v3.1 设计** (更清晰的分组):
```
QM+AB Registry (/dev/shm/lap_com_registry_qm, 权限 0666):
  - 槽位 0:      保留禁止使用 ❌
  - 槽位 1~1022: QM/ASIL-A/B 服务 ✅
  - 槽位 1023:   全局广播槽 📢

ASIL-CD Registry (/dev/shm/lap_com_registry_asil, 权限 0640):
  - 槽位 0:      保留禁止使用 ❌
  - 槽位 1~1022: ASIL-C/D 服务 ✅
  - 槽位 1023:   紧急广播槽 📢
```

**命名变更**:
- QM Registry → **QM+AB Registry** (包含 QM/ASIL-A/B 服务)
- ASIL-D Registry → **ASIL-CD Registry** (包含 ASIL-C/D 服务)

### 4. 广播槽位双向互通

**设计特性**:
- 所有进程订阅两个 Registry 的槽位 1023
- service_id 0xFFFF 同时写入两个 Registry
- 实现跨安全等级的系统级事件通知（OTA、休眠、紧急制动等）

**实现示例**:
```cpp
void SubscribeBroadcastSlots() {
    // 订阅 QM Registry 的槽位 1023
    qm_broadcast_slot_ = &qm_registry_->slots[1023];
    
    // 订阅 ASIL Registry 的槽位 1023
    asil_broadcast_slot_ = &asil_registry_->slots[1023];
    
    // 后台线程轮询两个广播槽（seqlock 检测更新）
}
```

### 5. Instance ID 位域结构

**v3.1 新增** 32位紧凑编码:

```cpp
struct alignas(4) InstanceId {
    uint32_t service_id      : 16;   // 0~65535，全车唯一
    uint32_t instance_no     : 8;    // 0~255，同服务多实例
    uint32_t domain          : 4;    // 0~15（感知/控制/娱乐等）
    uint32_t asil_level      : 3;    // 0=QM,1=A,2=B,3=C,4=D
    uint32_t redundancy      : 1;    // 0=主通道,1=备通道（ASIL冗余）
    // 总 32 bit，完美填满
};
```

**应用场景**:
- 域分类: PERCEPTION, CONTROL, INFOTAINMENT, DIAGNOSTICS, PLATFORM
- ASIL等级: QM, ASIL-A, ASIL-B, ASIL-C, ASIL-D
- 主备冗余: ASIL-D服务支持主备通道标识

### 6. 双层 IDL 设计

**v3.1 新增特性**:

```
Franca IDL (SSOT - Single Source of Truth)
    ↓ PyFranca 代码生成
AUTOSAR ara::com API (应用层)
    ↓ 自动转换
DDS IDL
    ↓ FastDDS-gen
DDS TypeSupport (传输层)
```

**关键优势**:
- ✅ Franca IDL 作为统一接口模型
- ✅ 强制版本一致性验证 (Schema Hash + TypeIdentifier)
- ✅ QoS 独立配置 (YAML)，不污染 IDL
- ✅ DDS 类型完全隔离，应用层零依赖

```yaml
# 双注册表架构 + 槽位 0 保护 + 广播互通
slot_mapping:
  # QM+AB Registry
  - service_id: 0x0001        # SD-Proxy 主实例
    instance_no: 1
    domain: PLATFORM
    asil_level: QM
    redundancy: false
    slot_index: 1             # 槽位 0 禁止
    registry: qm_ab
    
  # ASIL-CD Registry
  - service_id: 0xF001        # ASIL-D 主制动服务
    instance_no: 1
    domain: CONTROL
    asil_level: ASIL_D
    redundancy: false         # 主通道
    slot_index: 100
    registry: asil_cd
    
  - service_id: 0xF001        # ASIL-D 备份制动服务
    instance_no: 1
    domain: CONTROL
    asil_level: ASIL_D
    redundancy: true          # 备通道 ✅
    slot_index: 600
    registry: asil_cd
    
  # 广播服务
  - service_id: 0xFFFF        # 全局广播
    instance_no: 0
    domain: PLATFORM
    asil_level: QM
    redundancy: false
    slot_index: 1023
    registry: both            # 同时写入两个 Registry
    
registry_config:
  qm_ab:
    path: "/dev/shm/lap_com_registry_qm"
    size: 262144
    permissions: 0666
    reserved_slots: [0]       # 槽位 0 禁止使用
    broadcast_slot: 1023
    
  asil_cd:
    path: "/dev/shm/lap_com_registry_asil"
    size: 262144
    permissions: 0640
    reserved_slots: [0]       # 槽位 0 禁止使用
    broadcast_slot: 1023

slot_allocation:
  zero_conflict_mapping: true   # 启用零冲突映射
  slot_0_protection: true       # 强制槽位 0 保护
  broadcast_bidirectional: true # 启用广播双向互通
```

## 实施影响分析

### 代码变更范围

#### 1. SlotAllocator 类

**变更内容**:
```cpp
// v3.0
static constexpr uint16_t ComputeSlot(uint16_t service_id, uint16_t instance_id) {
    uint32_t hash = FNV1a(service_id, instance_id);
    return static_cast<uint16_t>(hash % 1024);
}

// v3.1
static constexpr uint16_t ComputeSlot(uint16_t service_id) {
    uint32_t slot = service_id & 1023;
    if (slot == 0) return INVALID_SLOT;  // 槽位 0 保护
    return static_cast<uint16_t>(slot);
}
```

**影响**:
- ✅ 简化实现，移除 instance_id 参数
- ✅ 添加槽位 0 保护逻辑
- ✅ 添加 SelectRegistry() 方法

#### 2. SharedMemoryRegistry 类

**变更内容**:
- 支持双注册表初始化
- 槽位 0 保护检查
- 广播槽位双向订阅

**新增方法**:
```cpp
Result<void> InitializeDualRegistry();
void SubscribeBroadcastSlots();
bool IsSlotReserved(uint16_t slot_id) const;
```

#### 3. 测试用例更新

**新增测试**:
- `TEST(SlotAllocatorTest, ZeroConflictMapping)`
- `TEST(SlotAllocatorTest, Slot0Protection)`
